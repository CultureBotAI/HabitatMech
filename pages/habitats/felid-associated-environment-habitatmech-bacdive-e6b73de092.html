  2. DEFINED 2026-08-26 · claude-opus-5

    Defined as 'felid-associated environment' under ENVO:01001002 'animal-associated environment'. Definition follows the established <clade>-associated environment family for BacDive host buckets, whose naming rule the corpus already fixes: a -inae source label yields -ine (Bovinae-Cow,-Cattle -> bovine) and a -idae source label yields -id (Equidae-Horse -> equid, Leporidae-Rabbit/Hare -> leporid, Suidae-Pig,Swine -> suid). No deep-research run was commissioned: the genus, the wording pattern and the near-miss reasoning are already settled by those five siblings and by NCBITaxon, so a billed report would add nothing this slice turns on. Worded like the equid sibling for the same reason as the canid row: NCBITaxon:9681 'Felidae' is wider than the domestic cat the source label names.
