## Findings

1. **Major M1: causal scope overreach.** Liquid-water identity does not
   entail high activity, a connected planktonic habitat, persistent particle
   suspension or all marine foraging outcomes. The first edge has direct
   counterevidence in its own cited liquid-media study. Owner:
   `curation/causal_graphs/liquid_water.yaml`; revise graph context, relevant
   nodes/edges and claim-level supporting passages, rather than removing valid
   marine mechanisms or changing habitat identity to pure water.
2. **Major M2: ENVO synonym scope inflated.** Official broad `water` is
   emitted exact. Owners: scoped ontology inventory/extraction and
   `src/habitatmech/seed.py:407`; this is another witness for #1249.
3. **Major M3: physical phase/biomass typed as cellular STATE.**
   `bulk_aqueous_phase` and `bacterial_biomass` are STATE nodes, but the schema
   defines STATE as a bioenergetic/molecular state of a cell. An external phase
   and community biomass stock are not such states. Owner: the maintained
   overlay, with schema extension only if no truthful existing representation
   suffices. The pathway enum explicitly permits pathway-like mechanisms, so
   hydrolysis/uptake labels alone are not separately flagged as wrong types.
4. **Minor m1: 13 MADIN source labels need a governed refresh or explicit
   separation from canonical names.** Owners: `extract.py:431-499`, versioned
   upstream MADIN/taxonomy inputs and manifests; preserve original labels as
   provenance. Related owner issue #1244; no IDs or associations should be
   silently replaced from name similarity.
5. **Minor m2: omitted parameter-source review event.** The water ITEM row
   exists but is not in generated history. `ingest_parameters` only records
   source counters and `decisions_applied` inside its new-concept branch
   (`seed.py:1308-1311`); water attaches to an existing concept. Owner: this
   maintained generator path. Count each source once, not once per band.
