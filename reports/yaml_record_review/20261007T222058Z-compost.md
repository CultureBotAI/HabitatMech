## Identity and Grounding

is active and agrees with the canonical label and material definition; its
response has no synonyms. The independently supported ontology parent is
[manure](https://www.ebi.ac.uk/ols4/api/ontologies/envo/terms?obo_id=ENVO%3A03501300),
whose scope includes plant-derived organic fertilizer, not only animal feces.
That parent is appropriate and must survive any source-parent correction.

Both GOLD contributions have ITEM GROUND/CLOSE decisions, for
`habitatmech:GOLD.4741a9f8bb` and `habitatmech:GOLD.981cf7502c`. Their notes
explicitly distinguish the composting process from the resulting material.
Nevertheless, ingestion emits both `Composting` and `Oil palm` as exact
synonyms. The record's aggregate EXACT status comes from direct ontology
identity sources; it does not upgrade these two `skos:closeMatch` attestations
to exact equivalence. Whether either qualified source should instead remain
separate requires original source-scope assessment, not a label-only split.

`mesh:D062611` comes from the first GOLD path's immediate `Solid waste`
parent. The complete parent record, raw path and `ingest_gold` parent pass
were inspected. The Oil palm path resolves its parent to the same compost
record, so the self-edge is skipped; it is not a second independent reason
for the MeSH parent. The local ENVO subclass row contributes only manure.

[NLM Solid Waste](https://meshb.nlm.nih.gov/record/ui?ui=D062611) describes
discarded materials. [EPA composting definitions](https://www.epa.gov/sustainable-management-food/composting)
distinguish waste inputs and the managed process from the stable soil-amendment
product. Compost may be waste-derived without every instance being discarded
waste. Thus the source bin does not support universal strict subclassing of
the generic compost material under Solid Waste. This is a modeling judgment,
not a claim about a jurisdiction's legal waste classification.

## Findings

1. **Major: CLOSE source labels are emitted as exact synonyms.** The two
   GOLD aliases contradict the curated non-equivalence rationale. Owner:
   `src/habitatmech/seed.py` source-synonym handling and regression tests;
   related open contract issue [#1459](https://github.com/CultureBotAI/HabitatMech/issues/1459).
   Preserve source spellings in attestations; do not upgrade the mappings.
2. **Major: unsupported Solid Waste superclass on generic compost.** The
   first GOLD source-path parent is feedstock/context evidence, not a universal
   genus of the finished material. Owner: a guarded
   `curation/gold_parent_exclusions.tsv` row for GOLD.4741a9f8bb, exact path
   `Engineered > Solid waste > Composting`, expected parent `mesh:D062611`.
   Keep independent ENVO:03501300 and all source provenance.
3. **Major: graph node types conflict with their defined semantics.**
   `organic_solid_waste` is material, not a physicochemical axis;
   `thermogenic_phase` is not the cellular molecular/bioenergetic state that
   the schema's STATE denotes; `thermophilic_bacteria` is a trait-defined
   functional group, not one organism or clade. Owner:
   `curation/causal_graphs/compost.yaml`; a genuine missing community/group
   representation may additionally need a deliberate schema extension.
   Passing enum validation does not resolve these distinctions.
4. **Minor: environment co-attestor review is absent from generated audit.**
   Owner: `ingest_parameters` in `src/habitatmech/seed.py`, with one-per-source
   registration tests. Existing open issue
   [#1264](https://github.com/CultureBotAI/HabitatMech/issues/1264) describes this
   contract. Do not count 11 parameter bands as 11 sources.
5. **Minor: two displayed MADIN names retain tokenized source formatting.**
   Owner: governed taxonomy-label extraction/source refresh for
   `data/raw/madin_habitat_taxa.tsv`, not generated YAML. Preserve the IDs,
