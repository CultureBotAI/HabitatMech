# Reconcile persisted native assertions before publication

Independent read-only review for CLAW #767 found that `export_assertions` hashes
the generated byte stream but reads persisted output back only to validate each
envelope and compare status counters. Reordering or duplicating valid rows with
the same review status can pass those checks while changing source membership.
The published digest would then describe generated rather than persisted bytes.

Before publishing the manifest, rehash the exact persisted JSONL bytes, verify
their byte count and ordered assertion/source-position identity against the
generated stream, and reject any mismatch. Add exporter-level mutation tests
that reorder or duplicate valid supported rows without changing status counts.
Repeat a real persisted canary after repair before rerunning the full export.

This does not authorize new scientific review or a predicate projection; native
decision scope remains unchanged. The analogous TaxonMech finding is issue #227.
